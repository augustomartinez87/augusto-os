## Investigar qué existe para implementar: Sistema — las restricciones del builder hablan de Prisma incluso en targets que no lo usan (F-0042)

**Resumen:** El feature F-0042 consiste en reemplazar la constante fija `RESTRICCIONES_ABSOLUTAS` de executor.ts (líneas 38-45), que hoy menciona Prisma incluso para targets dbModel:'none', por una función pura `buildRestriccionesAbsolutas(dbModel)` que arme el bloque según el modelo. Hay dos lugares de texto a unificar: el prompt del builder (buildPrompt en executor.ts, que ya tiene getTargetConfig() a mano) y el bloque inline propio del reviewer (reviewer.ts líneas 60-64), además del import en el fixer de escalación (escalation.ts). El tipo `dbModel?: 'prisma' | 'none'` ya existe en targets.ts y el default 'prisma' ya está establecido en db-guard.ts, y los tests existentes (escalation.test.ts) muestran el patrón de usar un target dbModel:'none' para evitar exigencias de env. El riesgo principal es mantener el caso 'prisma' byte a byte idéntico y no tocar db-guard/gates/qa, que quedan fuera de alcance.
